CONSEQUENCE HOOK
Two words. One denial. One appeal denied.
WHAT HAPPENED, INDIANA, 2024
"2 hours"
written on a session note instead of "8 units", same service, different record

An RBT at an Indiana clinic recorded "2 hours" on a session note instead of "8 units." The clinic billed 8 units. The payer paid for 8 units. When the OIG auditor reviewed the note and saw "2 hours," they flagged it as a documentation discrepancy. The claim was denied. The clinic appealed. The appeal was denied because the note said one thing and the claim said another.

Two hours is 8 units. The math was right. The service was real. The documentation was not. And that is all the auditor needed.

ABA billing runs on CPT codes, units, modifiers, and documentation standards that most non-clinical staff were never formally trained on. The RBT in Indiana was not trying to defraud anyone. She just did not know that "2 hours" and "8 units" are not interchangeable on a session note, even when they describe the same period of time.

This module closes that gap. By the time you finish it, you will understand what every ABA CPT code covers, who is qualified to deliver it, how time translates to units, what modifiers do and when they are required, and how the chain from session note to paid claim either holds together or breaks.

PART 1 OF CORE CONTENT
What CPT codes actually are, and why they matter to you.

A Current Procedural Terminology code, a CPT code, is a five-digit number that identifies a specific medical or behavioral health service for billing purposes. When a clinic submits a claim, the payer does not read the session note first. It reads the CPT code on the claim. The code tells the payer: what service was delivered, who is qualified to deliver it, and how long it took. Everything that follows, approval, denial, payment, audit, flows from that code.

CPT codes are not abbreviations

A CPT code is a formal legal billing designation. It describes a service to a level of specificity that carries legal weight in a payer contract. When a clinic bills 97153, it is representing to the payer that a technician delivered direct ABA treatment by protocol under BCBA supervision for the number of units listed. If the session note describes something different, a BCBA delivering the session, or a parent training session, or a group treatment, the code and the note disagree. That disagreement is an audit finding.

This is why the documentation coordinator's understanding of CPT codes matters. You are not responsible for clinical decisions. You are responsible for ensuring that what the note says matches what the claim says. That requires knowing what each code covers.

Who assigns CPT codes

CPT codes are developed and maintained by the American Medical Association. Payers then determine which codes they will reimburse, at what rates, and under what conditions. For ABA specifically, most payers cover the range from 97151 through 97158, the adaptive behavior codes. The 2027 transition adds six new codes to this range. Module 5 covers those in full. For now, the current code set is what you need to know.

PART 2 OF CORE CONTENT
The ABA CPT code breakdown, in plain language.

There are eight active ABA CPT codes from 97151 through 97158. Each one defines a different service type, a different provider requirement, and a different documentation standard. Getting one wrong on a claim is not a technicality, it is a documentation accuracy failure that the payer treats as misrepresentation of the service delivered.

97153 Adaptive behavior treatment by protocol Technician (RBT) under BCBA supervision Target programs addressed, client response, data recorded, supervisor identified

97158 Group adaptive behavior treatment with protocol modification BCBA or BCaBA, 2 or more clients All clients present, individual modifications for each client, clinical rationale

BCBA-delivered vs technician-delivered: the distinction that matters most

The most common billing error in ABA documentation is submitting a technician code when a BCBA delivered the service, or vice versa. 97153 is a technician code. 97155 is a BCBA code. If a BCBA delivers direct 1:1 ABA therapy, it cannot be billed under 97153, that code represents a technician-delivered service. The session note will say "BCBA," the code will say "technician," and the auditor will flag the mismatch. This is not a gray area.

PART 3 OF CORE CONTENT
Units vs hours, the most common documentation failure in ABA billing.

Time-based CPT codes are billed in 15-minute units. This is not a clinic policy, it is how the American Medical Association structured these codes, and every payer billing system processes them in units, not hours. One unit equals 15 minutes. Four units equals one hour. Eight units equals two hours. These are not interchangeable terms, they are different formats for the same information, and mixing them creates a documentation discrepancy that an auditor will catch.

Why the Indiana finding happened

The RBT wrote "2 hours" because that is how most people track time in everyday life. But the claim was submitted for "8 units" because that is how the billing system processes 97153 services. The two records are mathematically equivalent. The two records are not documentarily equivalent. An OIG auditor reviewing the note against the claim sees a note that says "2 hours" and a claim that says "8 units." Without a documented conversion methodology, those two records appear to conflict. That appearance of conflict is enough to trigger a denial.

The correct standard for session note time documentation

Session notes for time-based ABA codes should record time in units, the same format the billing system uses. The note should state: start time, end time, and total units delivered. If your clinic's RBTs are recording time in hours, that is a training gap that the documentation coordinator can flag and correct before an auditor finds it. It is not a clinical decision, it is a documentation standards issue, and it is exactly the kind of issue CADA is designed to catch.

Partial units and rounding

Most payers use an 8-minute rule for time-based codes: 8 minutes or more of a 15-minute unit may be billed as a full unit. Some payers have different rounding rules. The documentation coordinator should know the rounding policy for each payer in their clinic's payer mix. A session note documenting 22 minutes may support 1 or 2 units depending on the payer. Applying the wrong rounding rule to a note is a billing error, even if the clinical team performed the service correctly.

PART 4 OF CORE CONTENT
Modifiers, the codes that modify the codes.

A billing modifier is a two-digit code appended to a CPT code that provides additional information about the service. Modifiers do not change what the code describes, they tell the payer something specific about how the service was delivered, by whom, or under what circumstances. When a modifier is required by a payer and missing from the claim, the claim denies. When a modifier is attached incorrectly, the claim either denies or triggers a documentation review.

Common ABA billing modifiers and what they mean

  • HO, Delivered by a master's-level provider. Required by some payers for certain code-provider combinations.
  • HN, Delivered by a bachelor's-level provider. Required by specific payers to confirm provider credential level.
  • HM, Delivered by a less than bachelor's-level provider. Some payers require this for RBT-delivered services.
  • U1 through U9, State-specific modifiers. Meaning varies by state Medicaid program. California Medi-Cal uses different U modifiers than Indiana Medicaid.
  • GT, Via interactive audio and video telecommunications (telehealth). Required on any claim for a service delivered remotely. Incorrect use, attaching GT to an in-person service note, is a billing misrepresentation.
  • 95, Synchronous telemedicine service rendered via real-time interactive audio and video. Used by some commercial payers in place of or alongside GT.
  • 76, Procedure repeated by the same physician or other qualified health care professional. Used in some concurrent supervision scenarios.

Modifier requirements are payer-specific

No single modifier rule applies to every payer. Medi-Cal requires specific U modifiers. United Healthcare commercial requires different modifiers for different service types. TRICARE has its own modifier standards. The documentation coordinator cannot assume that because a modifier is required for one payer, it applies to all payers, or that because one payer does not require a modifier, no other payer will either. The payer-specific modifier requirements belong in the same payer rule reference you build in Module 6.

Concurrent billing restrictions

Most payers restrict billing certain codes concurrently, that is, for the same client at the same time. The most common restriction is 97151 and 97155 on the same date at overlapping times. Some payers also restrict simultaneous billing of 97155 and 97153 for the same client. When a documentation coordinator reviews weekly claims and finds two codes billed for the same client at overlapping times, the first check is whether that payer's billing guidelines allow that combination. Submit the concurrent claims first and address the denial later is the most expensive approach a documentation coordinator can take.

PART 5 OF CORE CONTENT
The documentation to billing chain, where it holds and where it breaks.

Every paid ABA claim is the end result of a chain that starts before the session begins and ends when the payment posts. That chain has five links. Break any one of them and you do not get paid, or you get paid and then owe it back. The documentation coordinator sits at the junction between the clinical world and the billing world. Understanding the chain is understanding your job.

The five-link chain

  1. Treatment plan, The BCBA writes a treatment plan that identifies target behaviors, intervention protocols, and service intensity. This plan is what the payer used to approve the authorization. Every service delivered must connect back to something in the treatment plan. A session note documenting a target that is not in the treatment plan is a documentation integrity gap.
  2. Authorization, The payer approves services as described in the treatment plan. The authorization specifies CPT codes, units, date range, eligible providers, and service location. Everything delivered must fit inside the authorization boundaries. Module 2 covers authorization in depth.
  3. Session note, The RBT or BCBA documents the specific service delivered: who delivered it, what targets were addressed, how long the session ran (in units), the client's response, and the supervisor's identification. The note is the legal record of the session. It must match the authorization in CPT code, provider type, units, and date.
  4. Claim, The billing team takes the session note and translates it into a claim: CPT code, units, modifier, diagnosis code, date of service, provider NPI, and authorization number. If the note says one thing and the claim says another, that is a billing error. The documentation coordinator's pre-submission review catches this before it becomes an audit finding.
  5. Remittance and payment, The payer processes the claim and either pays or denies. If the chain held together at every link, the claim pays. If it broke anywhere, a code mismatch, a missing modifier, a unit discrepancy, an unauthorized service location, it denies.

Where most errors enter the chain

In OIG audit findings across Indiana, Wisconsin, Maine, and Colorado, errors most commonly entered the chain at the session note level. The clinical team was delivering real services. The billing team was filing claims that matched the notes. But the notes themselves were inaccurate, wrong units, wrong time format, missing required elements, or descriptions that did not match the billed code. The documentation coordinator who catches a session note error before it reaches the billing team prevents a claim denial, an audit finding, and a potential recoupment demand.

LINE 3, DOCUMENTATION FORMAT ERROR

The session note says "3 hours." The claim says "12 units." This is the Indiana finding, repeated.

The math is correct: 3 hours = 12 units at 15 minutes per unit. But the session note says "3 hours" and the claim says "12 units." An auditor reviewing the note against the claim sees a format discrepancy. The note should read "Start: 9:00 AM, End: 12:00 PM, Total: 12 units." The documentation coordinator should return this note to the clinical team for correction before the claim is submitted, not convert it themselves, which creates a chain of custody issue, and not submit it as-is, which creates an audit exposure.

MODULE SCENARIO
A claim denied. A session note pulled. What are you looking for?
YOUR ROLE: DOCUMENTATION COORDINATOR

The Setup

It is Monday morning. The clinic's billing team forwarded you a denial notice that arrived Friday. The denial is for a claim submitted two weeks ago for a client named Daria R. The service date was October 14. The billed code was 97155. The payer denial code reads: "Clinical documentation does not support the service as billed."

You pull the session note from October 14. It describes a 60-minute session delivered by BCBA Ramirez. The note includes the client's name, the date, the BCBA's signature, and a description of the session: "Direct 1:1 ABA therapy targeting self-care skills. Client completed 8 of 10 trials. Data recorded."

Walk through three decision points.

DECISION POINT 1 OF 3
The claim was filed under 97155. Looking at the session note, what is the most likely reason for the denial?
A. The BCBA's signature is on the note, which is correct for 97155, so the denial must be a payer error.
B. The session note describes direct skills training with a client, which is 97153 activity. 97155 requires documentation of protocol modification, clinical analysis, or caregiver guidance delivered by the BCBA. The note does not contain any of that.
C. The note is missing the authorization number, which caused the denial.
DECISION POINT 2 OF 3
You confirm that the session description is 97153 activity delivered by a BCBA rather than by an RBT. What is the correct code for this service, and why?
A. Leave the code as 97155, the BCBA's presence qualifies any session for a BCBA code.
B. Change it to 97153, direct ABA treatment by any provider is billed as 97153.
C. Escalate to the BCBA and clinic director, the documentation coordinator cannot unilaterally change the billed code. The clinical team must review the note and determine whether the service was 97153 (technician-level activity performed by a BCBA) or whether the note simply failed to document 97155-qualifying activities that actually occurred.
DECISION POINT 3 OF 3
The BCBA confirms that October 14 was indeed a protocol modification session, but the note did not capture that correctly. The clinic director asks you to prepare the appeal. What must the appeal include?
A. A letter stating that the denial was a payer error and requesting immediate payment.
B. An amended or addended session note from the BCBA documenting the protocol modification activities that occurred, an explanation of why the original note did not capture those activities, and documentation of the BCBA's clinical reasoning supporting 97155 billing for the date of service.
C. A new session note written today describing what the BCBA says happened on October 14.
