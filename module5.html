PART 1 OF CORE CONTENT
Why 2027 changes everything — what is happening and why it matters for documentation.

The current ABA CPT code set — codes 97151 through 97158 — was established in 2019 when the AMA replaced the previous unlisted procedure codes that the ABA field had used for years. At the time, the 2019 codes were a dramatic improvement: specific, defined, provider-matched, and tied to measurable service types. For five years, the field built its documentation systems around them.

The 2027 update does not replace that framework. It expands it. CMS and the AMA determined that the existing codes did not adequately distinguish between several service types that differ meaningfully in clinical intensity and provider involvement. The result is six new permanent codes, two deleted Category III codes, and one significant split in an existing code — changes designed to improve specificity, reduce audit exposure for clinics doing legitimate work, and give payers cleaner data.

Why the documentation coordinator's role is central to this transition

A BCBA's clinical decisions do not change on January 1, 2027. The behavior analyst will still modify protocols. The RBT will still implement them. The parent will still receive training. What changes is how those services are described in documentation — and documentation is the documentation coordinator's domain.

Every session note written in January 2027 must include documentation elements that session notes written in December 2026 were not required to include. Every authorization written under old codes that extends into 2027 must be amended before the first January service date. Every PrioraCare template must be updated. These are not clinical changes. They are documentation infrastructure changes — and the documentation coordinator is the person responsible for them.

When payers begin accepting new codes

CMS sets the January 1, 2027 effective date for the new codes. Payers — including Medi-Cal and commercial insurers — typically open their billing systems to accept new codes starting 30 to 60 days before the effective date, in November or December 2026. This matters: a clinic that waits until January 1 to begin testing payer acceptance is a clinic that will not discover billing system errors until they affect real claims. Documentation coordinators should begin payer verification no later than mid-November 2026.

It also matters in the other direction. Some payers extend grace periods allowing submission of old codes for services rendered before January 1, even if the claim is submitted after. Knowing your payer's specific transition window is essential — and that knowledge requires a phone call or a written payer communication, not an assumption.

PART 2 OF CORE CONTENT
The six new codes — what each one covers and what documentation it requires.

Six new permanent CPT codes take effect January 1, 2027. Each one captures a service type that the existing code set either could not describe precisely or could only approximate using unlisted procedure codes. The documentation requirements for each new code are more specific than what the existing codes required — meaning session note templates must be updated before the first January 2027 service date.

97148
NEW — EFFECTIVE JAN 1, 2027

Group Adaptive Behavior Treatment

Direct treatment by protocol in a group setting, each 15 minutes. RBT delivered. Requires documentation of group composition, number of participants, and each client's target programs addressed in group.

97149
NEW — EFFECTIVE JAN 1, 2027

Caregiver Training Without Client Present

Adaptive behavior treatment guidance to caregiver or guardian, client not present, each 15 minutes. Note must document caregiver name, training topics, and client whose behavior program was discussed.

97159
NEW — EFFECTIVE JAN 1, 2027

Adaptive Behavior Assessment — Caregiver Interview

Assessment involving caregiver or guardian, 30 minutes minimum. Requires documentation of assessment purpose, caregiver responses, and how results will inform the behavior intervention plan.

97160
NEW — EFFECTIVE JAN 1, 2027

Protocol Modification — Analyst Not Present

BCBA modifies treatment protocol based on data review. Analyst is NOT physically present during the session. Note must document that the analyst reviewed session data remotely and specify the modification made.

97173
NEW — EFFECTIVE JAN 1, 2027

Protocol Modification — Analyst Physically Present

BCBA is physically present during the session and directly observes or supervises the protocol modification. Note must explicitly document analyst's physical presence and their direct involvement during the session.

97180
NEW — EFFECTIVE JAN 1, 2027

Non-Face-to-Face BCBA Time

The first standalone permanent code for indirect BCBA work — care coordination, supervision documentation, treatment plan revision, payer communication. Each 15 minutes. No client or caregiver present. Documents the time BCBAs spend that previously had no billable code.

What documentation coordinators must track for each new code

Each new code introduces a documentation element that the existing code set did not require. For 97148 (group treatment), the note must document the number of clients in the group — a field that existing session note templates often do not include. For 97149, the note must distinguish whether the client was present or absent during the caregiver training session. For 97173, the note must include a statement of analyst physical presence that existing 97155 notes often omit because it was implied.

The documentation coordinator's pre-transition job is to review every existing session note template and identify which fields are missing for each new code. PrioraCare templates must be updated to include those fields before December 31. If RBTs submit January session notes using December templates, the notes will not contain the required documentation elements — and the claims will be denied on documentation grounds.

PART 3 OF CORE CONTENT
The two deleted codes — and what happens to every authorization that references them.

Two Category III CPT codes — temporary codes used when a service does not yet have a permanent code — are deleted effective January 1, 2027. These codes are being retired because permanent replacement codes now exist. After December 31, 2026, no payer billing system will recognize these codes. Any claim submitted using either code will be automatically denied at the system level before it reaches a human reviewer.

0362T
DELETED — EFFECTIVE JAN 1, 2027

Adaptive Behavior Treatment with Protocol Modification — Physician/QHP

Category III code for protocol modification delivered by a physician or other qualified healthcare professional. Replaced by 97160 and 97173 in the permanent code set. Any authorization referencing 0362T that extends beyond December 31, 2026 must be amended before the first January 2027 service date.

0373T
DELETED — EFFECTIVE JAN 1, 2027

Exposure Behavioral Follow-Up Assessment

Category III code for follow-up behavioral assessment using exposure-based methodology. Folded into the expanded permanent assessment code set. Any authorization referencing 0373T that extends beyond December 31, 2026 must be amended to reference the applicable replacement code.

CRITICAL — AUTHORIZATION DEADLINE

An authorization written in October 2026 that authorizes 0362T services through April 2027 will not support any claim submitted after December 31, 2026. The payer's billing system will reject the code, and the authorization itself — even if still active by date — cannot be used to approve a claim for a code that no longer exists. The documentation coordinator must identify every active authorization referencing 0362T or 0373T and initiate amendment requests before December 31.

What "Category III" means and why these deletions happen

Category III codes are temporary. The AMA creates them when a new service needs a code before enough clinical evidence exists to establish a permanent code with fully defined documentation requirements. Category III codes are designed to sunset — they are either elevated to permanent status as the evidence base develops, or they are deleted as the service is absorbed into existing or new permanent codes.

0362T and 0373T are being deleted because the 2027 expansion of the permanent code set now covers the services those temporary codes described. This is a normal part of the CPT lifecycle — but it creates a documentation transition challenge when active authorizations reference codes that are being retired mid-authorization period.

The documentation coordinator's job is to catch this before the first January service date. That means pulling a list of every active authorization in PrioraCare that references either code, flagging each one, and initiating amendment requests with the payer before December 31. If the payer does not process the amendment before January 1 — a real possibility given holiday processing timelines — services authorized under those codes should not be delivered until a valid authorization for the replacement code is in place.

PART 4 OF CORE CONTENT
97155 split in two — the change that affects every BCBA in the country.

97155 is currently the most commonly billed code for BCBA-delivered ABA services. It covers adaptive behavior treatment with protocol modification — the BCBA reviews session data and adjusts the client's treatment protocol. Under the current code, whether the BCBA is physically present during the session or reviews the data remotely and communicates the modification to the RBT is irrelevant to the code billed. 97155 covers both.

Starting January 1, 2027, that distinction matters. 97155 is not being deleted — but it is being replaced by two new codes that separate these two service types:

97160
Protocol Modification — Remote
BCBA reviews session data and modifies the protocol. Not physically present during the session. RBT implements the modified protocol. Note must document: data reviewed, modification made, that analyst was not present during session delivery.
97173
Protocol Modification — In Person
BCBA is physically present during the session, directly observes the RBT, and modifies or directs the protocol in real time. Note must document: analyst's physical presence, direct observation, and specific protocol modification made during the session.

Why this split creates a documentation problem

Under the current 97155 structure, session notes often include language like "BCBA modified protocol per data review" without specifying whether the analyst was in the room. That language was sufficient for 97155. It is not sufficient for either 97160 or 97173 — because each code requires explicit documentation of the analyst's location during the session.

A session note that says "BCBA modified protocol" with no presence statement cannot be billed as either 97160 or 97173. If the payer's automated review flags the note for missing presence documentation, the claim will be denied — not because the service was not delivered, but because the note does not contain the required documentation element to support either new code.

Every PrioraCare session note template that currently supports 97155 must be updated before December 31. The update must add a mandatory presence field — a checkbox or required text field where the RBT or BCBA confirms whether the analyst was physically present during the session. Without that field, notes written in January will not contain the documentation the new codes require.

What to do with existing 97155 authorizations that extend into 2027

An authorization for 97155 services that runs through March 2027 is an authorization for a code that will effectively cease to exist as a primary billing code on January 1. The payer may still recognize 97155 for a transition period — or may not. The only way to know is to contact the payer and ask. If the payer does not plan to extend a 97155 grace period into January, the authorization must be amended to reference 97160, 97173, or both — depending on what the BCBA's service type will be for each session.

PART 5 OF CORE CONTENT
Preparing your documentation system — five actions every documentation coordinator must take before December 31.

The 2027 transition is not a one-day event. It is a documentation infrastructure project that must be completed over several weeks. A documentation coordinator who starts this process on December 28 will not finish it in time. The five actions below represent the minimum transition work required — and the CADA 2027 Transition Checklist in the Job Aid section expands each one into a 10-step implementation guide.

WHAT HAPPENS IF YOU SKIP THE PAYER VERIFICATION STEP

CMS guidance on new CPT codes is uniform. Individual payer billing system updates are not. A payer that has not updated its clearinghouse rules to accept 97173 by January 1 will reject every 97173 claim — not because the code is wrong, but because its system does not yet recognize it. Knowing each payer's actual go-live date before January 1 prevents the first week of January from becoming a denial management crisis.

WORKED EXAMPLE
A clinic that executed the 2027 transition correctly — step by step.

Inland Valley Behavioral Health is a mid-size California ABA clinic serving 48 clients across Medi-Cal and two commercial payers. Their documentation coordinator, working alone without outside consultants, completed the 2027 transition in 14 weeks. Here is what she did.

WEEK OF SEPTEMBER 15 — 15 WEEKS OUT
Template audit launched. The documentation coordinator pulled all 11 active session note templates from PrioraCare. She identified that none of them included a BCBA presence field — meaning every January 97155-equivalent session would be underdocumented under the new code set. She flagged this to the clinic director and began drafting the new template fields.
WEEK OF OCTOBER 6 — 12 WEEKS OUT
Authorization sweep completed. She identified 3 clients with active 0362T authorizations running through Q1 2027 and 7 clients with 97155 authorizations extending past December 31. She submitted amendment requests for the 3 0362T clients immediately. For the 7 97155 clients, she drafted amendment requests targeting 97160 or 97173 depending on how the BCBA described each client's service model.
WEEK OF NOVEMBER 10 — 7 WEEKS OUT
Payer verification completed. She called Medi-Cal, BlueCross, and Aetna. Medi-Cal confirmed a January 1 go-live for all new codes with a 30-day grace period for 97155 claims submitted through January 31. BlueCross confirmed January 1 go-live with no grace period. Aetna confirmed December 15 start date for new code acceptance. She documented all three responses with reference numbers and saved them to PrioraCare under the client files for each payer's client population.
WEEK OF DECEMBER 8 — 3 WEEKS OUT
Staff training completed. She sent written guidance to all 12 RBTs and both BCBAs explaining the 97155 split, with examples of what a 97160 note looks like versus a 97173 note. She ran a 20-minute team meeting on the documentation changes. She confirmed receipt via email from each staff member. She saved the training confirmation emails to PrioraCare.
DECEMBER 23 — 9 DAYS OUT
System update and test completed. Updated templates were activated in PrioraCare. She submitted a test claim for each new code to Aetna (which was already accepting them) and confirmed clearinghouse acceptance for all six new codes. On January 2, she ran an audit of all pending claims to verify no old codes appeared. The clinic's January claims went out clean on January 7.
WHY THIS WORKED

Four decisions that prevented a January denial crisis

She started early. Fifteen weeks is not excessive — it is what a full transition actually requires when you have amendment requests, payer calls, staff training, and template updates all running in parallel. A three-week timeline cannot absorb an amendment request that takes four weeks to process.

She documented everything. Every payer call had a reference number. Every staff training had a receipt. Every authorization sweep had a PrioraCare note. When the January audit ran clean, she had a complete paper trail showing exactly what was done and when — which is also her audit defense file if a payer later questions any January claim.

She escalated to the clinic director immediately. The template gap was not her error to fix alone. It required a decision about clinic resources, an IT update to PrioraCare, and a staff training budget. She surfaced the issue within days of the template audit — not weeks.

She ran a live test. Submitting a test claim to Aetna in December gave her confirmation that the new codes were actually accepted by that payer's billing system — not just that they should be, theoretically, per CMS guidance.
